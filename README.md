# Object-Oriented-Programming_-2_FinalProject
### Hotel Management System

A role-based Hotel Management System designed to manage hotel operations through three user roles: Admin, Staff, and Guest. The project includes feature-based system design, ER diagram and database normalization, user interface design, and UML diagrams such as Use Case and Activity Diagrams.

Key Areas: Admin Management • Staff Management • Guest Services • Database Design • ER Diagram • Normalization • UI Design • UML Diagrams
